# think releases

Signed, notarized builds of think, a Mac app for working with Thinking Surface, and the feed its built-in updater reads. The app's source is private; nothing else lives here.

- **Install:** download the newest `think-<version>.zip` from [Releases](https://github.com/jordkemp/think-releases/releases/latest), unzip it, and move think.app to Applications. Install.md inside the zip covers the rest.
- **Updates:** think checks `releases/latest/download/appcast.xml` once a day and offers new versions itself.
